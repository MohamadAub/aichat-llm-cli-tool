# aichat-llm-cli-tool
AIChat is an all-in-one LLM CLI tool with Shell Assistant, CMD &amp; REPL Modes, RAG, AI Tools, Agents, and Local Server support.   Integrates seamlessly with 20+ LLM providers like OpenAI, Claude, Gemini, Ollama, and more.   Features include role management, macro automation, session context, function calling, and local API endpoints.
